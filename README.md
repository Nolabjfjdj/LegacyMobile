# Minecraft LCE for Mobile

## About

This repository contains the original and (almost) untouched leaked source code of Minecraft Legacy Console Edition, adapted for mobile platforms.

The goal of this repository is to make Minecraft Legacy Console Edition build and run on mobile devices.

Feel free to open a pull request to fix any issue in the source code. However, I won't accept any that breaks mobile builds.

## Building for Mobile

### Requirements

1. A compatible development environment.
2. The required compilers and build tools for the target mobile platform.
3. Any required mobile SDKs and dependencies.

### Build

1. Open the appropriate project or solution file in a compatible development environment.
2. Set the configuration to `Release`.
3. Select the target mobile platform and architecture.
4. Build the project using the appropriate build command.

## Platform Support

This project focuses exclusively on mobile devices.

Supported platforms and architectures depend on the current state of the source code and the available build tools.
